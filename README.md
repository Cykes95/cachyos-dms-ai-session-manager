# AI Session Manager

DankMaterialShell widget for independent terminal sessions. It creates two isolated Codex homes and one Antigravity (`agy`) session by default. Credentials remain in the official CLIs and are never read or stored by this plugin.

Click the bar pill to select a profile, start its official login in Ghostty, or open its CLI. Codex profiles use separate `CODEX_HOME` directories under `~/.local/share/ai-session-manager/`.
